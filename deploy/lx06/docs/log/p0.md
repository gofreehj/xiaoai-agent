## 备注

1. `/usr/share/mico/version` 的首行 ROM 匹配命中注释 `# ROM ver`，没有读到版本号；
   1.94.13 来自设备的启动 banner 与 ROM 标识。
2. `/proc/mtd` 共 7 个分区。两个 system 槽位各 40 MiB（`0x02800000`），
   1.94.13 rootfs 为 37.5 MB，可放入单槽，余量约 2.5 MB。
3. `/data` 总量 13.4 MiB、可用 8.1 MiB。静态 musl Agent 二进制约 6.86 MB，
   可以放入，但只剩约 1.2 MiB；部署时不要保留第二份二进制。
4. 当前 `mipns-xiaomi` 仍带 `-r opus32`，这是原生基线。T2A 由
   `start-agent.sh` 在运行时移除该参数，并验证前端改为 PCM。
5. T2A 前的 socket inode 基线：`speech.usock` 11469、`common.usock` 11471
   （2026-11-18 17:57）。重启 `mico_aivs_lab` 后 `speech.usock` inode 应保持不变，
   `common.usock` 应被重建。
