# AGENTS.md —— 实现 Agent 的作业纪律

> 你是本项目的实现者。**先读完本文件，再动任何命令。**
> 这里的规则优先级高于任何"更快的做法"。

---

## 1. 你的目标

把 `deploy/lx06/` 从"规格"变成"设备上能跑的东西"：LX06 刷机后，设备自主完成语音闭环，不依赖后端。

目标设备：**小爱音箱 Pro（LX06）**，Amlogic 平台，ARMv7，A/B 双系统。

---

## 2. 开始前必须确认的三件事

1. **用户已明确同意刷机**（会失去保修、有变砖风险）。没有明确同意，只能做只读操作。
2. **设备型号确认为 LX06**（底部标签），不是 OH2P。
3. **P0 四条 gate 已跑完且全部通过**（`bash scripts/p0-check.sh <IP>`），才可进入 T2A。

缺任何一条 → 停下来问，不要"先试试"。

---

## 3. 硬规则（违反即失败）

### 刷机
- 只写 `boot0` / `boot1` / `system0` / `system1`。
- **永不写** `bootloader` / `tpl` / `data`。
- 写入前必须：只读备份 6 分区 → 比对确认在跑哪一边 → 只写**非活动**槽。
- 每次写入后必须 `mread` 回来**逐字节比对**，不一致立即停，不改启动参数。
- 分区尺寸必须来自**设备真实** `/proc/mtd`；不得沿用 OH2P 的 `0x2800000 / 0x600000`。
- 补丁打不上时**不许** `patch --fuzz` 硬打；停下来报告。
- 内核与系统必须来自同一个官方包、同一版本。

### 凭据
- 不要在聊天/日志/提交里出现 root 密码、token、API key。
- 密码由用户在终端交互输入；脚本用 `read -s` 或环境变量。
- 生成的 token 文件权限 `600`。

### 设备
- 不要在设备上跑本地 ASR/LLM（算力不够）。
- 不要改动原生系统分区里的文件（补丁除外）；运行时接管只放 `/data/`。
- 不要禁用看门狗/掉电保护。
- 不要把 4399 / 8003 / 9092 暴露到公网。

### 依赖
- 优先复用上游，不重写：`stevenjoezhang/xiaoai-agent`（LGPL-3.0）、`coderzc/open-xiaoai`（MIT）。
- 引入新依赖必须说明理由、许可证、以及是否可交叉编译到 `armv7-unknown-linux-gnueabihf`。
- LGPL 代码修改后分发需开源；本仓库内部使用不受影响，但要在 `NOTICE` 里记录来源。

## 4. 工作流程

```
P0 验证 ──┬─ 四条 gate 全过 → T2A：受控 speech.usock 接管探针
          └─ 任一 gate 失败 → 停止端侧实施，报告证据并转 bridge
```

每个任务（T0–T8）都必须：
1. 先写**验收标准**（可执行命令 + 期望输出）；
2. 实现；
3. 在真机上跑验收；
4. 把**命令与输出**贴进 `docs/log/`（新建）作为证据；
5. 才标记完成。

**不允许**用"代码看起来对"代替真机验证。

---

## 5. 证据要求

每条结论都要能回答"你怎么知道的"：
- 接口是否存在 → `ls -l` / `ps` 输出
- 音频是否有声 → 录一段、看波形/文件大小
- 唤醒是否生效 → 日志时间戳
- 是否与原生抢麦 → 同时喊两个词，看谁响应

报告格式：
```
[结论] 设备存在 speech.usock
[证据] $ ls -l /var/run/speech.usock
       srwxrwxrwx 1 root root 0 Nov 16 10:22 /var/run/speech.usock
[影响] 可走 A 方案
```

---

## 6. 什么时候必须停下来问人

- P0 gate 结果与预期不符（多一个、少一个、路径不同）
- 刷机任何一步读回校验失败
- 需要写 `bootloader` / `data` 才能继续
- 官方包找不到对应版本
- 需要付费开通第三方服务（ASR/TTS）
- 设备出现异常发热、重启循环、无响应
- 你打算"绕过"本文件的某条规则

---

## 7. 提交与文档

- 一次提交只做一件事；提交信息用中文，格式 `T3: 实现 usock 采集并落盘`
- 每个任务完成后更新 `docs/03-plan.md` 的状态列
- 新增脚本放 `scripts/`，必须 `set -euo pipefail`，必须幂等
- 所有脚本开头写用途、用法、前置条件、回滚方式

---

## 8. 禁止的"聪明"

| 不要做 | 因为 |
|---|---|
| "先刷了再说" | 变砖不可逆，A/B 只是缓解 |
| 跳过备份省时间 | 出问题时你没有任何退路 |
| 用 OH2P 的分区尺寸 | LX06 不同，会读出错误长度的"假备份" |
| 直接下载别人的 patched 镜像 | 版本/密码不可控，且可能被植入 |
| 让原生小爱保持可用又想接管麦克风 | 两者互斥，见 ADR-004 |
| 改 `client-rust` 的 WS 协议去"顺便兼容" | 会破坏与 bridge 的兼容性 |
